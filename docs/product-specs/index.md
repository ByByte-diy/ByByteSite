# Product Specifications

> **Purpose:** Define what the ByByte.DIY platform is, who it serves, and what it delivers.
> **Last updated:** 2025-07-20

## Product Overview

ByByte.DIY is a **STEM robotics educational platform** providing free, structured lessons for building and programming robotics kits (ByByte Nano, ByByte Mega, and third-party platforms like Arduino, Raspberry Pi, ESP32).

## Target Audience

| Persona | Need |
|---|---|
| **Self-learners** (teens, adults) | Free, structured robotics lessons in their language |
| **STEM teachers** | Ready-to-use lesson plans for classroom instruction |
| **Robotics club mentors** | Curated content for after-school programs |
| **Parents** | Educational activities for children at home |
| **ByByte kit owners** | Assembly guides and programming tutorials |

## Value Proposition

- **Free and open** — No paywalls, no accounts required
- **Multi-language** — English, Ukrainian, Russian; designed for easy expansion
- **Progressive** — Beginner to advanced, platform-specific tracks
- **Offline-capable** — Static site loads instantly anywhere
- **Community-driven** — Content contributions via GitHub
