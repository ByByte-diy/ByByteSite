## Button System

File: `src/app/shared/ui/button/`

### Variants

| Variant | Class | Usage |
|---|---|---|
| Primary | `btn--primary` | Main CTA, navigation |
| Secondary | `btn--secondary` | Alternative action |
| Accent | `btn--accent` | Highlighted action |
| Success | `btn--success` | Positive confirmation |
| Warning | `btn--warning` | Destructive confirmation step |
| Danger | `btn--danger` | Destructive action |
| Ghost | `btn--ghost` | Subtle, secondary links |
| Outline | `btn--outline` | Bordered, secondary CTA |

### Sizes

| Size | Class | Padding | Font | Height |
|---|---|---|---|---|
| sm | `btn--sm` | 0.5rem 1rem | --text-sm | 2rem |
| md | `btn--md` | 0.75rem 1.5rem | --text-base | 2.5rem |
| lg | `btn--lg` | 1rem 2rem | --text-lg | 3rem |
| xl | `btn--xl` | 1.25rem 2.5rem | --text-xl | 3.5rem |

### States

- `:disabled` / `btn--disabled`: opacity 0.5, cursor not-allowed
- `btn--loading`: animated spinner, cursor wait
- `:focus`: 2px solid --color-primary outline, 2px offset
- `:hover`: darker shade, translateY(-1px), box-shadow

### ButtonData Interface

```typescript
interface ButtonData {
  text: string;           // Translation key
  icon?: string;          // Emoji or icon character
  variant?: ButtonVariant;  // Default: primary
  size?: ButtonSize;        // Default: md
  disabled?: boolean;
  loading?: boolean;
  href?: string;          // Renders <a> instead of <button>
  target?: string;        // _blank, etc.
  type?: 'button' | 'submit' | 'reset';
}
```

## Theme System

File: `src/app/core/theme/theme.service.ts`

```typescript
type Theme = 'light' | 'dark' | 'system';
theme = signal<Theme>('system');  // Reactive state

setTheme(theme: Theme)            // Set and persist
getEffectiveTheme(): 'light'|'dark'  // Resolve system preference
```

- Default: `system` (respects `prefers-color-scheme`)
- Persistence: localStorage key `app-theme`
- DOM: toggles `theme-light` / `theme-dark` class on `<html>`
- SSR: mock adapters (no-op on server)

## Icon System

Icons use **CSS mask** approach for theme-aware coloring:

```scss
.icon {
  background-color: var(--icon-color);
  mask-image: url('/assets/icons/feature.svg');
  mask-size: contain;
  mask-repeat: no-repeat;
  -webkit-mask-image: url('/assets/icons/feature.svg');
  -webkit-mask-size: contain;
  -webkit-mask-repeat: no-repeat;
}
```

Colors controlled via CSS variables (`--icon-bg`, `--icon-color`).
