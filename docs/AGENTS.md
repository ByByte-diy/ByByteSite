# ByByte.DIY — Agent Guide

> **Audience:** AI coding agents and human collaborators onboarding to this codebase.
> **Last updated:** 2025-07-20

## One-Sentence Summary

ByByte.DIY is a **static Angular 20 standalone app** that serves multilingual STEM robotics lessons (Arduino, ESP32, Raspberry Pi) via GitHub Pages with full prerendering, i18n, and SEO.

## Quick Reference

| Attribute | Value |
|---|---|
| Framework | Angular 20 (standalone components, signals, functional providers) |
| Build | `@angular/build` application builder |
| Type | Static SPA (prerendered, no live SSR server) |
| Hosting | GitHub Pages |
| Domain | `https://www.bybyte.diy` |
| i18n | `@ngx-translate/core` — en (default), uk, ru |
| Styling | SCSS + CSS custom properties, light/dark themes |
| Testing | Karma + Jasmine (Firefox headless) |
| Linting | ESLint v9 (flat config), lint-staged pre-commit |
| Package manager | npm |
| Node | ^22 (specified in `.node-version` / CI) |

## Core Architecture

### Routing

Angular standalone `Routes` with a two-level structure:

```
/                       → RootPageComponent (redirects to default language)
/:lang                  → LanguageWrapperComponent (detects lang from URL param)
  /                     → Home
  /build                → BuildPage
  /learn                → LessonsList (lazy module)
  /learn/:platform      → Filtered by platform
  /learn/:platform/:level/:slug  → LessonDetail
  /community            → Community
  /blog                 → BlogComponent
  /terms                → TermsComponent
  /privacy              → PrivacyComponent
  /**                   → NotFoundComponent
```

- `languageGuard` validates the `:lang` param against `supportedLangs`
- `defaultLanguageRedirectGuard` redirects `/` to `/{defaultLang}`
- All routes under `/:lang` are prerendered.

### Multi-language i18n

- Translation files: `src/assets/i18n/{en,uk,ru}.json`
- Key structure: dot-notation (e.g. `seo.home.title`, `nav.build`)
- Language detection priority: URL prefix → localStorage (`app-lang`) → browser language → `en`
- **SSR/Prerendering**: translations loaded synchronously from filesystem via `fs.readFileSync`
- **Browser**: translations loaded via HTTP with automatic fallback to default language on 404

### SSR / Prerendering

The app uses **full static prerendering** (not a live SSR server). Built with:

1. `scripts/generate-prerender-routes.cjs` — generates `prerendered-routes.txt` with all language-localized paths
2. Angular application builder prerenders each route at build time
3. Output: `dist/ByByteSite/browser/` with static HTML per route

Result: each language variant has its own HTML file with correct meta tags and content.

### SEO

- `SeoService` (`src/modules/seo/services/seo.service.ts`) manages all meta tags
- Uses translation keys (never hardcoded strings)
- Supports: title, description, keywords, OG tags, Twitter Cards, JSON-LD structured data
- `updateSeoFromConfig(config, additionalData?)` is called in every page's `ngOnInit()`
- `updateLessonSeo(lesson, platform, level, slug)` for lesson detail pages

### Theming

- CSS custom properties scoped under `.theme-light` / `.theme-dark` classes on `<html>`
- `ThemeService` respects `prefers-color-scheme` (system), localStorage override, manual toggle
- Icons use CSS `mask-image` for theme-aware coloring

### CSS Conventions

- Class names: BEM-like (`.block__element--modifier`)
- Custom properties: `--color-*`, `--text-*`, `--font-*`, `--spacing-*`
- Breakpoints defined in SCSS with responsive mixins

## Key Patterns Agents Must Follow

### Adding a new page

1. Add route in `src/app/app.routes.ts` (inside `sharedRoutes`)
2. Add translations to all 3 language files under appropriate keys
3. Call `seoService.updateSeoFromConfig()` in `ngOnInit()`
4. Regenerate prerender routes: `npm run generate-prerender-routes`

### Using the RouterService

```typescript
// Instead of raw router.navigate(), use:
this.routerService.navigateTo('/build');
this.routerService.switchLanguage('uk');
```

### Injecting Services

```typescript
private readonly seoService = inject(SeoService);
private readonly translate = inject(TranslateService);
```

### Writing a component

```typescript
@Component({
  selector: 'app-my-thing',
  standalone: true,
  imports: [CommonModule, TranslateModule],
  templateUrl: './my-thing.html',
  styleUrls: ['./my-thing.scss'],
})
export class MyThing implements OnInit {
  ngOnInit(): void {
    // SEO setup
  }
}
```

## Build & Test Commands

```bash
npm start                              # Dev server (live reload)
npm run build                          # Production build + prerender
npm test                               # Karma/Jasmine (Firefox headless)
npm run lint                           # ESLint
npm run generate-prerender-routes      # Regenerate prerender route list
npm run generate-index                 # Regenerate lesson index.json
npm run validate-content               # Validate lesson frontmatter
```
