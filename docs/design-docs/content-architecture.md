# Content Architecture

> **Purpose:** Document how lesson content is structured, validated, indexed, and delivered.
> **Last updated:** 2025-07-20

## Content Repository

Lessons live in a **separate GitHub repository**: [ByByte-diy/ByByteLessons](https://github.com/ByByte-diy/ByByteLessons)

This separation ensures:
- Lesson authors do not need to touch the site codebase
- Content updates do not require Angular expertise
- The content repo can be open for community contributions independently

## Directory Structure

```
ByByteLessons/
├── content/
│   ├── en/                          # English lessons
│   │   ├── arduino/
│   │   │   ├── beginner/            # Difficulty level
│   │   │   │   ├── blink.md
│   │   │   │   └── intro.md
│   │   │   └── intermediate/
│   │   ├── raspberry/
│   │   └── esp32/
│   ├── uk/                          # Ukrainian lessons
│   └── ru/                          # Russian lessons
└── assets/
    ├── images/
    └── diagrams/
```

Path formula: `content/{lang}/{platform}/{level}/{slug}.md`

## Lesson Data Model

See `src/modules/lessons/models/lesson.model.ts`:

```typescript
interface LessonMeta {
  title: string;           // Lesson title
  slug: string;            // Unique identifier (used in URL)
  lang: string;            // Language code (en, uk, ru)
  platforms: string[];     // Target platforms: arduino, raspberry, esp8266, esp32
  level: 'beginner' | 'intermediate' | 'advanced';
  tags: string[];          // Search/filter tags
  published: boolean;
  version: string;         // Semantic version
  description?: string;    // Short SEO description
  author?: string;
  updatedAt?: string;
  createdAt?: string;
}

interface Lesson extends LessonMeta {
  content: string;         // Markdown body
  contentPath: string;     // Path to source file
}

interface LessonIndex {
  lessons: LessonMeta[];   // All lesson metadata
  platforms: string[];     // Unique platforms
  levels: string[];        // Unique levels
  tags: string[];          // Unique tags
  languages: string[];     // Unique languages
}
```

## Frontmatter Specification

Each lesson Markdown file begins with YAML frontmatter:

```yaml
---
title: "Lesson Title"
slug: "unique-slug"
lang: "uk"
platforms: ["arduino"]
level: "beginner"
tags: ["LED", "digital outputs"]
published: true
version: "1.0.0"
description: "Short description for SEO and listing"
duration: "30 min"
difficulty: "easy"
---
```

### Required Fields

| Field | Type | Validation |
|---|---|---|
| `title` | string | Non-empty |
| `slug` | string | Unique within language+platform |
| `lang` | string | One of: en, uk, ru |
| `platforms` | array of strings | Each in: arduino, raspberry, esp8266, esp32 |
| `level` | string | One of: beginner, intermediate, advanced |
| `published` | boolean | — |
| `version` | string | Semver pattern |

### Optional Fields

| Field | Type | Purpose |
|---|---|---|
| `tags` | string[] | Filtering and search |
| `description` | string | SEO meta description, card preview |
| `duration` | string | Display hint (e.g. "30 min") |
| `difficulty` | string | Display hint (e.g. "easy", "medium", "hard") |
| `author` | string | Attribution |
| `createdAt` | string | ISO date |
| `updatedAt` | string | ISO date |

## Content Pipeline

```
ByByteLessons repo (content source)
  │
  ▼ GitHub Actions: update-content.yml (manual trigger)
  │
  ├── Clone ByByteLessons repo
  ├── Copy content/ → src/assets/content/
  ├── Run scripts/generate-index.js
  │     └── Parses frontmatter from all .md files
  │     └── Generates src/assets/content/index.json
  ├── Run scripts/validate-content.js
  │     └── Validates required fields, data formats, slug uniqueness
  │     └── Reports errors/warnings
  └── Commit and push
        │
        ▼ GitHub Actions: ci.yml (triggered by push)
        │
        ├── npm ci && npm run build
        ├── npm test
        └── Deploy to GitHub Pages
```

## Generated Index Format

`src/assets/content/index.json` is generated by `scripts/generate-index.js`:

```json
{
  "lessons": [
    {
      "title": "Blinking LED",
      "slug": "blink",
      "lang": "uk",
      "platforms": ["arduino"],
      "level": "beginner",
      "tags": ["LED", "digital outputs"],
      "published": true,
      "version": "1.0.0",
      "description": "Classic blinking LED example for Arduino"
    }
  ],
  "platforms": ["arduino", "raspberry", "esp32"],
  "levels": ["beginner", "intermediate", "advanced"],
  "tags": ["LED", "sensors", "motors"],
  "languages": ["en", "uk", "ru"]
}
```

This index is loaded by `LessonsService` to power filtering, search, and navigation without reading individual Markdown files.
