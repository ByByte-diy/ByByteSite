# Lesson Index Schema

> **Purpose:** Document the auto-generated `index.json` schema for AI agents and tooling.
> **Source:** Generated by `scripts/generate-index.js` during CI.
> **Last updated:** 2025-07-20

## Location

`src/assets/content/index.json` (generated, not committed)

## Schema

```typescript
interface LessonIndex {
  /** All published lessons metadata */
  lessons: LessonMeta[];

  /** Unique platform names across all lessons */
  platforms: string[];   // e.g. ["arduino", "raspberry", "esp32", "esp8266"]

  /** Unique difficulty levels */
  levels: string[];       // e.g. ["beginner", "intermediate", "advanced"]

  /** Unique tags across all lessons */
  tags: string[];         // e.g. ["LED", "sensors", "motors", "I2C"]

  /** Unique language codes */
  languages: string[];    // e.g. ["en", "uk", "ru"]
}

interface LessonMeta {
  title: string;
  slug: string;
  lang: string;           // en | uk | ru
  platforms: string[];    // arduino | raspberry | esp8266 | esp32
  level: string;          // beginner | intermediate | advanced
  tags: string[];
  published: boolean;
  version: string;        // semver
  description?: string;
  author?: string;
  updatedAt?: string;     // ISO date
  createdAt?: string;     // ISO date
}
```

## Usage

| Consumer | Purpose |
|---|---|
| `LessonsService` | Loads index, provides filtering/sorting |
| `LessonsListComponent` | Renders filtered lesson cards |
| `LessonFilterComponent` | Populates filter dropdowns (platforms, levels) |
| Prerender route generator | Reads lessons to generate lesson detail routes |
