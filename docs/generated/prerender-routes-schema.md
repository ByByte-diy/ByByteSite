# Prerender Routes Schema

> **Purpose:** Document the `prerendered-routes.txt` format used by the Angular build.
> **Source:** Generated by `scripts/generate-prerender-routes.cjs` before `ng build`.
> **Last updated:** 2025-07-20

## Location

`prerendered-routes.txt` (project root, generated before build)

## Format

One route per line, no trailing slash except root:

```
/
/en
/en/build
/en/learn
/en/learn/arduino
/en/learn/arduino/beginner
/en/learn/arduino/beginner/blink
/uk
/uk/build
...
```

## Generation Logic

The script in `scripts/generate-prerender-routes.cjs`:

1. Reads `src/assets/content/index.json` (lesson index)
2. Generates localized routes for each language in `['en', 'uk', 'ru']`
3. Includes base pages: `/`, `/build`, `/community`, `/products`, `/docs`, `/blog`, `/learn`
4. Includes dynamic lesson routes: `/{lang}/learn/{platform}/{level}/{slug}`
5. Includes platform and level listing routes: `/{lang}/learn/{platform}`, `/{lang}/learn/{platform}/{level}`
6. Deduplicates and writes to `prerendered-routes.txt`

**Note:** The language list is currently hardcoded in the script. If languages are added/removed from `environment.ts`, the script must be updated manually.

## Consumption

Angular application builder (`@angular/build`) reads this file and prerenders each listed route into a static HTML file at build time:

```
dist/ByByteSite/browser/
├── index.html          (route: /)
├── en/
│   ├── index.html      (route: /en)
│   ├── build.html      (route: /en/build)
│   └── learn/
│       ├── index.html  (route: /en/learn)
│       └── ...
├── uk/
└── ru/
```
